# Grill Me

Start a `/grilling` session.

State that the session will examine the user's plan one decision at a time, provide a recommended answer for every question, and wait for feedback before continuing.

Do not solve, implement, edit, or execute the plan during the interview. End the session only after the user confirms that the shared understanding is complete.
